# Мониторинг доступности сайтов

Публичная страница статусов 36 сайтов: **UP**, **DOWN**, **Ограничен**, **Ожидается проверка**.

## Запуск

1. В GitHub откройте **Settings → Pages → Build and deployment → Source** и выберите **GitHub Actions**.
2. Затем откройте **Actions → Проверка доступности сайтов → Run workflow** и запустите первый мониторинг.
3. После успешного развёртывания страница будет доступна по адресу **https://maximfrontender.github.io/site-monitor/**.

Мониторинг запускается по расписанию каждый час (23-я минута UTC), возможны задержки планировщика GitHub. Запуск на push также предусмотрен. Каждая проверка делает HTTP(S)-запросы из GitHub Actions, а не из вашего браузера.

Сайты перечислены в `sites.txt`; проверки выполняет `monitor.py`, результаты публикуются в `site/status.json`, интерфейс находится в `site/index.html`.

**Важно:** статусы 401, 403, 429 означают ограничение проверки; доступность из Беларуси или России может отличаться от доступности с серверов GitHub. GitHub может отключить запланированные workflow после 60 дней без активности в публичном репозитории. Контролируйте последние обновления страницы и вкладку Actions. Здесь нет уведомлений — только веб-страница.
