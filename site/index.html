Доступность проверяется с серверов GitHub, поэтому может отличаться от доступности из вашей страны. Код 401, 403 или 429 означает, что автоматическая проверка ограничена. Кнопка «Обновить» запускает внеочередную проверку через GitHub Actions после авторизации. Публикация результатов может занять несколько минут.

Внеочередная проверка

Чтобы кнопка могла запускать GitHub Actions, нужен fine-grained токен GitHub с доступом только к репозиторию maximfrontender/site-monitor и разрешением Actions: Read and write.

Токен используется только для запроса к api.github.com и хранится исключительно в памяти открытой вкладки. После перезагрузки страницы его придётся ввести снова.
