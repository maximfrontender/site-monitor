# Мониторинг доступности сайтов

Публичная страница статусов 36 сайтов: **UP**, **DOWN**, **Ограничен**, **Ожидается проверка**.

## Запуск

1. В GitHub откройте **Settings → Pages → Build and deployment → Source** и выберите **GitHub Actions**.
2. Затем откройте **Actions → Проверка доступности сайтов → Run workflow** и запустите первый мониторинг.
3. После успешного развёртывания страница будет доступна по адресу **https://maximfrontender.github.io/site-monitor/**.

Мониторинг запускается по расписанию каждые 10 минут (UTC: :00, :10, :20, :30, :40, :50); из-за очередей GitHub Actions фактический запуск может задерживаться или иногда пропускаться. Запуск на push также предусмотрен. Каждая проверка делает HTTP(S)-запросы из GitHub Actions, а не из вашего браузера.

Сайты перечислены в `sites.txt`; проверки выполняет `monitor.py`, результаты публикуются в `site/status.json`, интерфейс находится в `site/index.html`.

**Важно:** статусы 401, 403, 429 означают ограничение проверки; доступность из Беларуси или России может отличаться от доступности с серверов GitHub. GitHub может отключить запланированные workflow после 60 дней без активности в публичном репозитории. Контролируйте последние обновления страницы и вкладку Actions. Здесь нет уведомлений — только веб-страница.
## Внеочередная проверка по кнопке «Обновить»

Страница размещена на GitHub Pages и является статической: без авторизации она **не имеет права** запускать GitHub Actions. Поэтому добавлен безопасный способ запуска через GitHub REST API:

1. Один раз создайте **Fine-grained personal access token**: https://github.com/settings/personal-access-tokens/new
2. Resource owner: `maximfrontender`; Repository access: **Only select repositories → site-monitor**.
3. Repository permissions → **Actions → Read and write**. Не давайте токену дополнительные разрешения.
4. Откройте https://maximfrontender.github.io/site-monitor/, нажмите **↻ Обновить**, вставьте токен в диалог **на своей странице** и подтвердите запуск.
5. После этого в текущей вкладке следующие нажатия **↻ Обновить** запускают проверку сразу. Страница опрашивает результаты и обновляется после публикации.

**Безопасность:** токен не сохраняется в исходниках, репозитории, localStorage или cookies; он используется только для авторизации запроса к `api.github.com` и хранится в памяти текущей вкладки. Перезагрузка страницы удаляет его. Никогда не отправляйте токен в чат. Желательно ограничить срок действия токена.

**Без ввода токена на странице:** https://github.com/maximfrontender/site-monitor/actions/workflows/monitor.yml → **Run workflow** (требуется вход в GitHub и права записи в репозиторий).

**Обратите внимание:** кнопку нужно нажать и подтвердить авторизацию, а сама проверка и публикация идут в GitHub Actions; появление новых данных может занять несколько минут. Повторное нажатие не ускоряет выполняющуюся проверку. Интерфейс показывает предупреждение, если результаты старше 30 минут.
